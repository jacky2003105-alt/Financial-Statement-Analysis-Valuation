# 財務報表分析與評價｜課堂重點整理（第一～六週）

政大「財務報表分析與評價」課程筆記網站。左邊是每一頁教材原圖，右邊是中文整理與老師課堂補充。
算式由 KaTeX 排版，程式、樣式與字型都放在 `assets/katex/`，**不連外網，離線一樣看得到公式**。

## 怎麼用

- 右上角**下拉選單**切換單元。
- **「隱藏解答，自我測驗」**：把題目頁的算式、解析與老師補充收起來，只留題目，可以直接當練習卷作答；再按一次恢復。
- 點**原圖可以放大**。
- 每頁與每個單元都附 **PDF 下載**，匯入 Goodnotes 可以手寫註記。

頁首標題上的「PDF 第 8/21 頁」指的是教材 PDF 檔案的第幾頁，「投影片印刷頁碼 9」指的是投影片右下角印的頁碼，兩者常常不一樣。第二週的 `sessions1-6_merged.pdf` 是掃描合併檔，上面沒有印投影片頁碼，所以只標檔案頁數。

## 部署到 GitHub Pages

1. 把這個資料夾的內容推上 repo（根目錄要有 `index.html` 與 `.nojekyll`）。
2. Settings → Pages → Source 選 `main` 分支的 `/ (root)`。
3. 全站都用相對路徑，放在 `https://<帳號>.github.io/<repo>/` 這種子路徑底下也能正常運作。

## 怎麼改內容

`整理工作檔/製作程式/notes_manifest.json` 是唯一的內容來源，`index.html` 是產物，直接改會被下一次重建蓋掉。
重建步驟固定（順序不能換）：

```bash
cd 整理工作檔/製作程式
./rebuild.sh
```

`rebuild.sh` 會依序做：反解析原始成品 → 無損檢查 → 頁首標籤與樣板句 → 算式的人工校訂 →
幣值符號 → 公式區塊 → 內文算式批次改寫 → 逐頁補寫 → 白話收尾 → 易錯提醒 → 問答標籤與分號 →
產生 `index.html` → 用瀏覽器實測 KaTeX 有沒有錯誤、畫面上有沒有殘留的純文字算式。

製作程式與教材原檔不放進發布包。
