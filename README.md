## 怎麼用

- 右上角**下拉選單**切換單元。
- **考試範圍選單**（全部／期中／期末）：只列出該範圍的單元。新聞導讀在每個範圍都會出現，期中考題目放在「期中」，第九週接續講完的「成長率、終值與每股價值」同時屬於期中與期末。選擇會記在瀏覽器裡，下次打開還是同一個範圍。
- **「隱藏解答，自我測驗」**：把題目頁的算式、解析與老師補充收起來，只留題目，可以直接當練習卷作答；再按一次恢復。
- 點**原圖可以放大**。
- 每個單元都附**整章 PDF**，匯入 Goodnotes 可以手寫註記。
- **概念連結**（期中考與之後的單元）：虛線底的詞是前面教過的概念。滑鼠移上去會顯示一兩句定義與「為什麼這樣算」，點下去跳到講到它的那一頁，右下角會出現「回到」按鈕，按了回到剛才讀的位置（瀏覽器的上一頁也可以）。手機上第一下先顯示定義，再點定義框裡的「前往」或同一個詞第二下才跳頁。

頁首標題上的「PDF 第 8/21 頁」指的是教材 PDF 檔案的第幾頁，「投影片印刷頁碼 9」指的是投影片右下角印的頁碼，兩者常常不一樣。第二週的 `sessions1-6_merged.pdf` 是掃描合併檔，上面沒有印投影片頁碼，所以只標檔案頁數。

## 部署到 GitHub Pages

1. 把這個資料夾的內容推上 repo（根目錄要有 `index.html` 與 `.nojekyll`）。
2. Settings → Pages → Source 選 `main` 分支的 `/ (root)`。
3. 全站都用相對路徑，放在 `https://<帳號>.github.io/<repo>/` 這種子路徑底下也能正常運作。

## 怎麼改內容

內容一律改資料檔，`notes_manifest.json` 與 `index.html` 都是產物，直接改會被下一次重建蓋掉：
前六週是原始成品反解析之後，再套 `content.py`、`formulas.py` 這些資料檔；期中考在 `midterm.py`；第九週在 `w9_news.py`、`w9_vps.py`、`w9_mul.py`；
概念連結的定義與連到哪一頁在 `concepts.py` 與 `concepts_w9.py`，寫錯 id 或頁面不存在時重建會直接失敗，不會產生死連結。
重建步驟固定（順序不能換）：

```bash
cd 整理工作檔/製作程式
./rebuild.sh
```

`rebuild.sh` 會依序做：反解析原始成品 → 無損檢查 → 頁首標籤與樣板句 → 算式的人工校訂 →
幣值符號 → 公式區塊 → 內文算式批次改寫 → 逐頁補寫 → 白話收尾 → 易錯提醒 → 問答標籤與分號 →
術語表 → 期中考單元 → 第九週（新聞、每股價值、倍數法、考試範圍） → 產生 `index.html` →
用瀏覽器實測 KaTeX 有沒有錯誤、畫面上有沒有殘留的純文字算式 → 期中考與第九週更新單元的整章 PDF。

製作程式與教材原檔不放進發布包。
