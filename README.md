## 怎麼用

- 右上角**下拉選單**切換單元。
- **頁首導覽列**（所有課程單元）：每頁最上面標出這一頁在整個流程的哪一步（倍數法是「定義、描述、分析、應用」，每股價值是「從營運資產價值走到每股價值」的哪一段，會計、DCF、現金流、成長率各單元依簡報的段落），並用一句話說這一頁在做什麼。
- **搜尋**：頁首的「搜尋」可以搜尋所有單元的內容，點結果直接跳過去並標出關鍵字。
- **記住讀到哪裡**：關掉再打開時，會回到上次讀到的那一頁。
- **不熟標記**：每一題旁邊有「標記不熟」，勾選頁首的「只看不熟」就只顯示有標記題目的頁面。標記存在你自己的瀏覽器裡。
- **本頁大綱**：按頁首的「本頁大綱」才會浮出目前單元的所有頁面（標出讀到哪裡），點一頁或按 Esc 就收起，不佔閱讀版面。
- **全部解答**：頁首與右下角的「隱藏全部解答／顯示全部解答」一次收起或打開這個單元所有題目的解答，和每題的按鈕同步。
- **考試範圍選單**（全部／期中／期末）：只列出該範圍的單元。新聞導讀在每個範圍都會出現，期中考題目放在「期中」，期中考之後才教的「每股價值」與「倍數法」放在「期末」。選擇會記在瀏覽器裡，下次打開還是同一個範圍。
- **會計分錄**：能用借貸分錄說清楚的地方（應計基礎、資本支出與折舊、商譽、遞延所得稅、股票薪酬、租賃與研發資本化、股利與庫藏股、權益法、持股評價利益）附分錄表。
- **每題的「隱藏解答／顯示解答」**：解答預設顯示；期中考、練習題、隨堂題、題解與 Concept Check 每一題各有一個按鈕，按了只收起那一題，可以一題一題當練習作答。
- **Concept Check**（八個課程單元，共 53 段、150 題）：每個單元依主題切段，每段最後一頁後面插一頁 Concept Check。題目照期中考的出題方式自編：英文題幹附中文題意，四選一或計算題，干擾選項都是一種常見的算錯或想錯，解析逐一說明，解析裡的頁碼可以直接點回講義那一頁。和期中考同類型的題目會標出「期中考同類題」。DCF 與成長兩個單元最後各有一組綜合計算題（Orchid Holdings 的資金成本、Lumen Devices 的每股價值），結構和期中考兩題申論相同。**這些題目不是老師出的**，每一頁開頭都有註明。
- 點**原圖可以放大**。
- 每個單元都附**整章 PDF**，匯入 Goodnotes 可以手寫註記。
- **概念連結**（所有單元）：虛線底的詞是教過的概念，每一頁第一次出現的專有名詞都有。滑鼠移上去會顯示一兩句定義與「為什麼這樣算」，點下去跳到講到它的那一頁，右下角會出現「回到」按鈕，按了回到剛才讀的位置（瀏覽器的上一頁也可以）。手機上第一下先顯示定義，再點定義框裡的「前往」或同一個詞第二下才跳頁。

頁首標題上的「PDF 第 8/21 頁」指的是教材 PDF 檔案的第幾頁，「投影片印刷頁碼 9」指的是投影片右下角印的頁碼，兩者常常不一樣。第二週的 `sessions1-6_merged.pdf` 是掃描合併檔，上面沒有印投影片頁碼，所以只標檔案頁數。

## 部署到 GitHub Pages

1. 把這個資料夾的內容推上 repo（根目錄要有 `index.html` 與 `.nojekyll`）。
2. Settings → Pages → Source 選 `main` 分支的 `/ (root)`。
3. 全站都用相對路徑，放在 `https://<帳號>.github.io/<repo>/` 這種子路徑底下也能正常運作。

## 怎麼改內容

內容一律改資料檔，`notes_manifest.json` 與 `index.html` 都是產物，直接改會被下一次重建蓋掉：
前六週是原始成品反解析之後，再套 `content.py`、`formulas.py` 這些資料檔；期中考在 `midterm.py`；第九週在 `w9_news.py`、`w9_vps.py`、`w9_mul.py`；第十週在 `w10_news.py`、`w10_mul.py`、`w10_apply.py`；
Concept Check 的題目在 `cc_intro.py`、`cc_acct.py`、`cc_dcf.py`、`cc_cash.py`、`cc_growth.py`、`cc_vps.py`、`cc_mul.py`、`cc_mul_w10.py`、`cc_apply.py`（共用的格式在 `concept_check.py`）；
概念連結的定義與連到哪一頁在 `concepts.py`、`concepts_w9.py` 與 `concepts_auto.py`（自動連結的寫法也在這裡），寫錯 id 或頁面不存在時重建會直接失敗，不會產生死連結。
重建步驟固定（順序不能換）：

```bash
cd 整理工作檔/製作程式
./rebuild.sh
```

`rebuild.sh` 會依序做：反解析原始成品 → 無損檢查 → 頁首標籤與樣板句 → 算式的人工校訂 →
幣值符號 → 公式區塊 → 內文算式批次改寫 → 逐頁補寫 → 白話收尾 → 易錯提醒 → 問答標籤與分號 →
術語表 → 期中考單元 → 第九週（新聞、每股價值、倍數法、考試範圍） → Concept Check → 產生 `index.html` →
用瀏覽器實測 KaTeX 有沒有錯誤、畫面上有沒有殘留的純文字算式 → 各單元的整章 PDF。

製作程式與教材原檔不放進發布包。
